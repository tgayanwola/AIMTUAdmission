# AI University Admissions System — Vercel Ready

## Scoring
- A1=10, B2=9, B3=8, C4=7, C5=6, C6=5
- WAEC Aggregate = (sum of five grade points / 50) * 40
- JAMB Aggregate = (JAMB / 400) * 60
- Total Score = WAEC Aggregate + JAMB Aggregate

## Prototype admission thresholds
- 70–100: Admission Recommended
- 50–69.99: Further Review
- below 50: Not Admitted

Replace thresholds with the institution's formally approved policy before production.

## Local
npm install
npm run dev

## Vercel
Push this folder to GitHub, import it in Vercel, and deploy. Vercel detects Next.js automatically. No environment variables are required for this prototype.
